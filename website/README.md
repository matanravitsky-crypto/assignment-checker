# website/: האתר

האתר עצמו: HTML, CSS ו-JavaScript, בלי בנייה ובלי ספריות חוץ מ-KaTeX (לנוסחאות). **כל מה שהוא מציג אמיתי**: הנתונים מגיעים מהמערכת שרצה במחשב ([`dashboard/`](../dashboard/), `start.bat`), שקוראת את תיקיית OneDrive של הקורס. בלי המערכת האתר לא מציג מספרים, רק הסבר איך מתחברים.

- **https://bodek-hacham.vercel.app** (מתפרסם לבד ב-Vercel מ-`main` בכל שינוי בתיקייה הזו, פרויקט `bodek-hacham`, תיקיית שורש `website`): פונה למערכת שבמחשב בכתובת `http://127.0.0.1:8765`. בפעם הראשונה כרום שואל אם לאפשר לאתר לגשת לאפליקציות ולשירותים במכשיר; עונים "אפשר". כל עוד start.bat לא פועל, האתר מנסה להתחבר שוב כל 5 שניות.
- **http://localhost:8765**: אותם קבצים, ישירות מהמערכת.

השרת מקבל בקשות רק מהמחשב עצמו ורק מהכתובת המדויקת של האתר ב-Vercel (לא מכתובות תצוגה מקדימה). ראו "אבטחה" ב-[`dashboard/README.md`](../dashboard/README.md).

| קובץ | מה הוא |
|---|---|
| `index.html` | המעטפת: ניווט, סרגל עליון, טעינת הסקריפטים |
| `app.js` | כל המסכים: לוח בקרה, משיכה, בדיקה, החזרה, יומן והגדרות, וגם החיבור למערכת (`connect`, `api`, `loadLocal`) |
| `styles.css` | העיצוב, בהיר וכהה, מימין לשמאל |

המספרים מתעדכנים רק ממה שנכתב בתיקייה: הגשות ב-"1 - Submissions to grade", ציונים ב-Grades.csv ועבודות מסומנות ב-"2 - Graded with comments", והעלאות שאומתו ב-Upload log.csv. גם יומן הפעילות נבנה מהתיקייה (`_activity` ב-`dashboard/actions.py`).

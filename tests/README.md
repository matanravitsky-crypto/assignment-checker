# tests/: הבדיקות

כל הבדיקות רצות משורש הריפו:

```bash
python -m pytest
```

ההגדרות נמצאות ב-`pytest.ini`. ב-GitHub הבדיקות רצות לבד בכל Pull Request, דרך `.github/workflows/tests.yml`.

| תיקייה | מה נבדק |
|---|---|
| `moodle/` | המספור, טבלת המפתח, הכנת ההחזרה, הסטטוס וקובצי ההסבר |
| `grading/` | הבדיקה עם Claude מדומה בלבד: מה נשלח (בלי שמות ובלי טבלת המפתח), Grades.csv, שורות מאושרות, הסימון על ה-PDF והגודל שלו |
| `dashboard/` | איתור התיקייה המשותפת, המצב לאתר בלי שמות, המשיכה וההחזרה, הנעילה, ואבטחת השרת |
| `stats/` | מסד הנתונים הסטטיסטי: אותם מספרים כמו באתר, בלי שום פרט מזהה, ו-`test_fuzz.py`: אלפי מטלות אקראיות עם קלט עוין (`STATS_FUZZ_SEEDS=100000` להרצה ארוכה) |
| `sample_files.py` | יוצר קובצי PDF ו-ZIP לדוגמה, בפורמט של מודל, עם שמות בדויים |
| `fakes.py` | נהג העלאה מזויף לבדיקות בלבד (`FakeDriver`). המערכת עצמה עובדת רק מול מודל האמיתי |

הבדיקות לא נוגעות בתיקייה המשותפת האמיתית. הן בונות עותק מוקטן בתיקייה זמנית.

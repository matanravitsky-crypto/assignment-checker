# בודק חכם

מערכת לבדיקה אוטומטית של תרגילי בית במתמטיקה בדידה ובאלגברה לינארית.

| שלב | מה קורה | איפה הקוד | מצב |
|---|---|---|---|
| 1. משיכה | Claude בכרום מוריד ממודל את ה-ZIP של כל ההגשות, והן ממוספרות בלי שמות ונשמרות בתיקייה המשותפת ב-OneDrive | [`moodle/`](moodle/) | עובד |
| 2. בדיקה | Claude בודק כל עבודה לפי המחוון, מסמן הערות על הדף ונותן ציון | [`grading/`](grading/) | עובד, דרך Claude Code שמחובר במחשב (או מפתח API) |
| 3. החזרה | העבודות המסומנות עולות למודל דרך Claude בכרום, אחרי אישור של אדם. הציונים עולים בינתיים ידנית | [`moodle/`](moodle/) | עובד |

## האתר

**https://bodek-hacham.vercel.app** הוא האתר של כולם. הוא מציג רק נתונים אמיתיים, מתוך התיקייה המשותפת ב-OneDrive, והם מגיעים מהמערכת שרצה במחשב של מי שפותח אותו (`start.bat`). בלי המערכת האתר לא מציג מספרים, ויש בו כפתור **"פתח את המערכת"** שמוביל ל-`http://localhost:8765`: אותו אתר, ישירות מהמערכת, עם כל הכפתורים.

## הפעלה אצל כל אחד מהצוות

**פעם אחת בכל מחשב:**
1. **גישה לתיקייה:** מבקשים מהמרצה גישה לתיקייה `YallaLinearit`. בדפדפן, על התיקייה: **Add shortcut to My files**. באפליקציית OneDrive במחשב מתחברים עם חשבון האוניברסיטה, והתיקייה מסתנכרנת לבד.
2. **התוכנות** (בחלון PowerShell או שורת הפקודה):
   ```bash
   winget install Python.Python.3.12
   winget install 7zip.7zip
   winget install Git.Git
   ```
3. **המערכת:** סוגרים ופותחים מחדש את החלון, עוברים לתיקייה שבה רוצים לשמור אותה (למשל שולחן העבודה), ומורידים:
   ```bash
   git clone https://github.com/matanravitsky-crypto/assignment-checker
   ```

4. **הפעלה אוטומטית:** לוחצים פעמיים על **`install-autostart.bat`** בתיקייה `assignment-checker`. מעכשיו המערכת עולה לבד, בלי חלון, בכל פעם שהמחשב נדלק.

**בכל פעם:** פשוט פותחים את https://bodek-hacham.vercel.app (או `http://localhost:8765`), והכל עובד. מי שלא התקין הפעלה אוטומטית לוחץ פעמיים על **`start.bat`** ומשאיר את החלון השחור פתוח. מה שהמערכת כותבת כשהיא רצה בלי חלון נשמר ב-`%TEMP%odek-hacham.log`.
- `start.bat` (גם בהפעלה האוטומטית) **מעדכן את המערכת מ-GitHub בכל הפעלה** (`git pull` של `main`), כך שכל הצוות רץ על אותה גרסה. בהפעלה הראשונה ההתקנה לוקחת כדקה.
- **לכל שלושת השלבים** צריך Claude Code מחובר במחשב, ולמשיכה ולהעלאה גם את התוסף Claude in Chrome בכרום, עם התחברות למודל. האתר בודק את זה בעצמו (רשימת המוכנות בשלב 3) ומציע להתקין ולהתחבר. `start.bat` מעדכן את Claude Code בכל הפעלה: גרסה ישנה לא מריצה את המודלים החדשים.
- **הבדיקה** (שלב 2) רצה דרך Claude Code, במנוי של הצוות. מפתח API בקובץ `.env` הוא לא חובה (ראו למטה).

**כל אחד בצוות יכול למשוך.** טבלת המפתח היא אחת, בתיקייה המשותפת, וכל סטודנט שומר על המספר שלו לא משנה מי משך. שתי הגנות מונעות התנגשויות:
- **נעילה:** בזמן משיכה נוצר בתיקיית המטלה הקובץ `Pull in progress.txt`, ומי שמושך באותו זמן מקבל הודעה לחכות.
- **עותק כפול:** אם OneDrive יצר עותק כפול של טבלת המפתח, האתר מציג אזהרה ולא מושך עד שמתקנים.

## התיקייה המשותפת

כל הנתונים נמצאים ב-`YallaLinearit/Exercise Checking System` (ב-OneDrive של המרצה), ולא בריפו. **הריפו ציבורי**, ולכן לא מעתיקים אליו שום קובץ של סטודנטים.

```
Exercise Checking System/
  <קורס>/                             למשל "Linear Algebra"
    <מטלה>/                           למשל "Assignment 0 - Sets and Complex Numbers"
      Assignment details.json         מזהה במודל, מועד הגשה, שאלות, שם בעברית
      Key - number to student.csv     טבלת המפתח: מספר ↔ סטודנט. השמות נמצאים רק כאן
      1 - Submissions to grade/       0001.pdf, 0002.pdf... ממוספרות, בלי שמות
      2 - Graded with comments/       אותו מספר, עם ההערות (שלב הבדיקה)
      Official solution.pdf           הפתרון הרשמי, אם יש. נשלח ל-Claude עם כל הגשה
      3 - Ready to upload to Moodle/  מה שמוכן להעלאה (שלב ההחזרה)
      Grades.csv                      number,grade,feedback (מה שהבדיקה מחזירה)
      Moodle download <תאריך>.zip     ה-ZIP בדיוק כפי שמודל נתן
```

השמות של כל התיקיות והקבצים מוגדרים במקום אחד: [`moodle/paths.py`](moodle/paths.py).

## עבודה על הקוד

- עובדים בענף ופותחים Pull Request. `main` משתנה רק דרך PR.
- **הבדיקות:** בכל PR הבדיקות רצות לבד ב-GitHub. כדי להריץ אותן במחשב:
  ```bash
  python -m pytest
  ```
- **מפתח Claude (לא חובה):** בלי מפתח הבדיקה רצה דרך Claude Code שמחובר במחשב. מי שרוצה לבדוק דרך ה-API שומר מפתח בקובץ `.env` בשורש הריפו, במחשב בלבד. הקובץ לא עולה ל-GitHub:
  ```
  ANTHROPIC_API_KEY=...
  ```

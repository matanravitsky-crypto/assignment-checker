# onedrive/: העלאה אוטומטית לוואן דרייב של המרצה

במקום לגרור את תיקיית הקורס לוואן דרייב וללחוץ "Replace" על הכל, הסקריפט `sync.js` מעלה **רק מה שחדש או השתנה**, ובודק בסוף שהכל הגיע.

## איך זה עובד

1. **השרת המקומי** (`start.bat`, כתובת `http://127.0.0.1:8765`) נותן דרך `/api/sync/`:
   - את רשימת הקורסים,
   - את רשימת הקבצים בכל קורס (נתיב, גודל, מתי נשמר),
   - ואת הקבצים עצמם.
   הכל מתוך `~/Exercise Checking System` (`ASSIGNMENT_DATA`), רק לקריאה, ורק לוואן דרייב של האוניברסיטה (`https://bgu365-my.sharepoint.com`). `Moodle originals`, עם שמות הסטודנטים, לא שם ולא יוצא מכאן (`dashboard/sync.py`).
2. **הסקריפט** רץ בלשונית של הוואן דרייב של המרצה, עם ההרשאות של מי שמחובר בה:
   - קורא את רשימת הקבצים מהשרת המקומי,
   - משווה לוואן דרייב (דרך הממשק הפנימי של SharePoint),
   - מעלה רק את מה שצריך.
3. **בסוף** הוא משווה שוב, ומדווח בחלון קטן בפינת הדף וב-`window.__ecsSync`.

## מה עולה ומה לא

| מצב | מה קורה |
|---|---|
| קובץ שאין בוואן דרייב | עולה |
| קובץ במחשב שנשמר אחרי הגרסה בוואן דרייב | עולה ומחליף |
| אותו גודל, ולא חדש יותר | לא נוגעים |
| בוואן דרייב חדש יותר (למשל `Grades.csv` שהצוות עדכן) | **לא נדרס**, ומופיע בדוח |
| מנעולים (`... in progress.txt`), קבצים זמניים | לא עולים |
| קובץ שיש רק בוואן דרייב | נשאר. **הסקריפט לא מוחק כלום** |

## איך מריצים

Claude, בלשונית של הוואן דרייב של המרצה (Claude in Chrome, `javascript_tool`):

```js
eval(await (await fetch("http://127.0.0.1:8765/api/sync/script.js")).text());
await window.__ecsSyncAll({ dryRun: true });   // רק השוואה: מה היה עולה
await window.__ecsSyncAll();                   // העלאה
```

כל ריצה היא כמה קריאות קצרות: הקבצים עוברים מהמחשב לוואן דרייב דרך הדפדפן ולא דרך Claude, ולכן זה כמעט לא עולה טוקנים, ואין מגבלה של 10MB.

בלי שרת מקומי: בחלון יש גם כפתור "בחירת תיקיית קורס". בוחרים את התיקייה ביד, והסקריפט משווה ומעלה באותה דרך.

## פעם אחת בכל מחשב

- כרום שואל אם לאפשר לאתר של הוואן דרייב לגשת לרשת המקומית: לוחצים **"אפשר"**.
- `start.bat` צריך לרוץ, ולשונית של הוואן דרייב של המרצה צריכה להיות פתוחה, עם חשבון האוניברסיטה מחובר.

## לא להעלות באמצע בדיקה

אם בתיקיית המטלה יש `Grading part N in progress.txt`, בדיקה רצה עכשיו. מחכים שהיא תסתיים, ורק אז מסנכרנים, כדי שלא יעלו ציונים חלקיים.

נבדק ב-23/10 על הוואן דרייב של המרצה:
- קובץ של 12MB עלה מהמחשב ב-10 שניות, וחזר זהה (SHA-256).
- רשימה של 550 קבצים התקבלה בחצי שנייה.
- בהשוואה יבשה, מתמטיקה בדידה יצאה זהה לגמרי (96 קבצים).

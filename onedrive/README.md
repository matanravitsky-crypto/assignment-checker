# onedrive/: העלאה אוטומטית לוואן דרייב של המרצה

במקום לגרור את תיקיית הקורס לוואן דרייב וללחוץ "Replace" על הכל, הסקריפט `sync.js` מעלה **רק מה שחדש או השתנה**, ובודק בסוף שהכל הגיע.

## ממשק

| | |
|---|---|
| **נכנס** | `/api/sync/` של הדשבורד במחשב (`http://127.0.0.1:8765`: רשימת קורסים, רשימת קבצים ומצב הסנכרון, הבתים), או תיקייה שבוחרים ביד |
| **יוצא** | הקבצים בוואן דרייב של המרצה (SharePoint REST, בהרשאות של מי שמחובר), עם `down: true` גם הקבצים מהוואן דרייב במחשב (`/api/sync/put`), ודוח ב-`window.__ecsSync` |
| **רץ** | בלשונית הוואן דרייב של המרצה, דרך Claude in Chrome (`javascript_tool`) |
| **תלוי ב** | רק ב-API של הדשבורד, ב-HTTP. בלי קוד פייתון של המערכת |

## איך זה עובד

1. **השרת המקומי** (`start.bat`, כתובת `http://127.0.0.1:8765`) נותן דרך `/api/sync/`:
   - את רשימת הקורסים,
   - את רשימת הקבצים בכל קורס (נתיב, גודל, מתי נשמר),
   - ואת הקבצים עצמם.
   הכל מתוך `~/Exercise Checking System` (`ASSIGNMENT_DATA`), רק לקריאה, ורק לוואן דרייב של האוניברסיטה (`https://bgu365-my.sharepoint.com`). `Moodle originals`, עם שמות הסטודנטים, לא שם ולא יוצא מכאן (`dashboard/sync.py`).
2. **הסקריפט** רץ בלשונית של הוואן דרייב של המרצה, עם ההרשאות של מי שמחובר בה:
   - קורא את רשימת הקבצים מהשרת המקומי,
   - משווה לוואן דרייב (דרך הממשק הפנימי של SharePoint),
   - מעלה רק את מה שצריך.
3. **בסוף** הוא משווה שוב, ומדווח בחלון קטן בפינת הדף וב-`window.__ecsSync`.

## מה עולה ומה לא

| מצב | מה קורה |
|---|---|
| קובץ שאין בוואן דרייב | עולה |
| קובץ במחשב שנשמר אחרי הגרסה בוואן דרייב | עולה ומחליף |
| אותו גודל, ולא חדש יותר | לא נוגעים |
| בוואן דרייב חדש יותר (למשל `Grades.csv` שהצוות עדכן) | **לא נדרס**, ומופיע בדוח |
| מנעולים (`... in progress.txt`), קבצים זמניים | לא עולים |
| קובץ שיש רק בוואן דרייב | נשאר. **הסקריפט לא מוחק כלום** |
| קובץ של בדיקה (עבודה מסומנת, `Grading notes`, `Who grades what`, `Grades*.csv`) שחסר בוואן דרייב, כשבוואן דרייב הבדיקות של המטלה הועברו ל-`Old test grading/` והקובץ במחשב נשמר לפני ההעברה | **לא עולה**, כדי לא להחזיר בדיקות ישנות. הדוח אומר כמה, וממליץ להעביר אותם גם במחשב. זמן ההעברה הוא הזמן של `Old test grading/README.txt` בוואן דרייב. מה שנבדק אחרי ההעברה עולה כרגיל |

## איך מריצים

Claude, בלשונית של הוואן דרייב של המרצה (Claude in Chrome, `javascript_tool`):

```js
eval(await (await fetch("http://127.0.0.1:8765/api/sync/script.js")).text());
await window.__ecsSyncAll({ dryRun: true });   // רק השוואה: מה היה עולה
await window.__ecsSyncAll();                   // העלאה
```

כל ריצה היא כמה קריאות קצרות: הקבצים עוברים מהמחשב לוואן דרייב דרך הדפדפן ולא דרך Claude, ולכן זה כמעט לא עולה טוקנים, ואין מגבלה של 10MB.

בלי שרת מקומי: בחלון יש גם כפתור "בחירת תיקיית קורס". בוחרים את התיקייה ביד, והסקריפט משווה ומעלה באותה דרך.

## בשני הכיוונים: גם מוריד למחשב (Mac)

ב-Mac אפליקציית OneDrive לא יכולה לסנכרן את התיקייה של המרצה: חשבונות הצוות (post.bgu.ac.il) הם אורחים בארגון
של BGU, BGU דורשת מאורחים אימות דו-שלבי, ולפי מיקרוסופט אפליקציית הסנכרון לא מציגה חלון התחברות לתוכן של
ארגון אחר. ב-Windows עוקפים את זה דרך WAM (הסקיל teammate-setup), וב-Mac אין לזה מקבילה. בדפדפן האימות כן
מופיע, ולכן הסקריפט יודע גם להוריד:

```js
eval(await (await fetch("http://127.0.0.1:8765/api/sync/script.js")).text());
await window.__ecsSyncAll({ down: true, dryRun: true });   // רק השוואה: מה היה עולה ומה היה יורד
await window.__ecsSyncAll({ down: true });                 // בשני הכיוונים (או הכפתור "בשני הכיוונים" בחלון)
```

`up: false` רק מוריד. בלי `down` רק מעלה, כמו קודם, עם הבדל אחד: קובץ שהשתנה גם בוואן דרייב מאז הסנכרון הקודם
כבר לא נדרס בהעלאה. הוא מדווח כהתנגשות.

| מצב | מה קורה |
|---|---|
| קובץ שיש רק בוואן דרייב | יורד למחשב (`/api/sync/put`), עם הזמן שלו בוואן דרייב |
| השתנה רק בוואן דרייב מאז הסנכרון הקודם | יורד ומחליף |
| השתנה רק במחשב | עולה |
| השתנה בשני הצדדים | **התנגשות**: לא נוגעים באף צד, ומופיע בדוח |
| סונכרן פעם ונמחק או הועבר באחד הצדדים | לא חוזר. מופיע בדוח |
| השתנה במחשב בין ההשוואה להורדה | השרת מסרב (409), לא נדרס |
| טבלת מפתח בוואן דרייב שחסר בה סטודנט שיש במחשב, או מספר אחר | לא יורד כלום מהמטלה, ומדווחים |
| מנעול טרי (`* in progress.txt`) של המטלה בוואן דרייב, או במחשב הזה | לא יורד כלום מהמטלה עכשיו |
| תיקיית הנתונים במחשב היא תיקייה ש-OneDrive מסנכרן בעצמו | לא יורד כלום: OneDrive כבר מביא |

"מאז הסנכרון הקודם" נקבע לפי מצב הסנכרון: לכל קובץ שסונכרן, הגודל והזמן שלו במחשב ובוואן דרייב באותו רגע.
הוא נשמר במחשב בלבד, ב-`Moodle originals/OneDrive sync state/<קורס>.json` (`dashboard/sync.py`). קובץ שעוד
לא סונכרן מהמחשב הזה: גודל שונה = הצד שנשמר אחרון (בהפרש של יותר משתי דקות; פחות מזה = התנגשות), אותו גודל =
זהה, ומעכשיו נרשם. כלום לא נמחק, באף צד.

ההורדה הראשונה ל-Mac ריק מביאה את כל הקורסים, כולל ההגשות (יכול להיות כמה GB): כדאי קודם `dryRun` לראות כמה MB.

## פעם אחת בכל מחשב

- כרום שואל אם לאפשר לאתר של הוואן דרייב לגשת לרשת המקומית: לוחצים **"אפשר"**.
- `start.bat` צריך לרוץ, ולשונית של הוואן דרייב של המרצה צריכה להיות פתוחה, עם חשבון האוניברסיטה מחובר.

## לא להעלות באמצע בדיקה

אם בתיקיית המטלה יש `Grading part N in progress.txt`, בדיקה רצה עכשיו. מחכים שהיא תסתיים, ורק אז מסנכרנים, כדי שלא יעלו ציונים חלקיים.

נבדק ב-23/10 על הוואן דרייב של המרצה:
- קובץ של 12MB עלה מהמחשב ב-10 שניות, וחזר זהה (SHA-256).
- רשימה של 550 קבצים התקבלה בחצי שנייה.
- בהשוואה יבשה, מתמטיקה בדידה יצאה זהה לגמרי (96 קבצים).

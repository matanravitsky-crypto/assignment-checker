# moodle/: הורדה ממודל והחזרה למודל

שלבים 1 ו-3. למודל אין API, ולכן ההורדה וההעלאה נעשות בדפדפן, והקוד כאן עושה את כל השאר.

| קובץ | מה הוא עושה |
|---|---|
| `paths.py` | השמות של כל התיקיות והקבצים בתיקייה המשותפת. כל קוד אחר לוקח אותם מכאן |
| `ingest.py` | שלב 1: לוקח את ה-ZIP מ-Downloads, מחלץ עם 7-Zip וממספר |
| `anonymize.py` | המספור (`0001.pdf`…) וטבלת המפתח. כל סטודנט שומר על המספר שלו בכל הורדה |
| `upload.py` | שלב 3: בונה את גיליון הציונים ואת קובצי ה-ZIP של המשוב, עם הוראות העלאה |
| `upload_log.py` | יומן ההעלאה (`Upload log.csv`) ורשימת האצווה (`Upload batch.json`): מה הועלה לכל מספר, בלי שמות. מספר נחשב מוחזר רק אם כל הקבצים שלו זהים להעלאה האחרונה |
| `send.py` | הכנת אצווה להעלאה (`prepare_batch`): רק עבודות בדוקות חדשות או ששונו מאז ההעלאה האחרונה, ארוזות ב-ZIP-ים של עד 9 MB, עם `Upload batch.json`. מספר שהוגש מחדש אחרי הבדיקה, או שיש לו קובץ גדול מדי, נשאר בחוץ. מדווח על אלה ועל מספרים שלא אושרו ב-`Grades.csv` (בלי שמות) |
| `claude_driver.py` | ההעלאה למודל דרך Claude in Chrome: ריצה אחת נעולה של `claude -p --chrome` לכל ZIP (רק כלי Chrome, רק תיקיית ההעלאה, עם תקציב וזמן מוגבלים), והפיכת התשובה שלה ל-`UploadResult`. לא זורק חריגות: כל כשל חוזר כתוצאה `error` עם הודעה בעברית. `check` ו-`auth_status` בודקים שכרום, מודל ו-Claude Code מוכנים |
| `claude_upload.md` | תבנית ההוראות ל-Claude (`str.format`, בלי סוגריים מסולסלים חוץ מהשדות): כתובת אחת, שלבי ההעלאה, ובדיקה יבשה שנעצרת בביטול לפני הייבוא (הייבוא במודל מיידי, בלי מסך אישור) |
| `lock.py` | קובץ נעילה בתיקיית המטלה, כדי ששני אנשים לא יריצו את אותו שלב על אותה מטלה יחד. המשיכה משתמשת בו |
| `status.py` | מה כבר נעשה במטלה, ואילו שמות קבצים OneDrive יסרב לסנכרן |
| `guide.py` | קובצי `README.txt` בעברית בתוך התיקייה המשותפת |

## פקודות

```bash
python -m moodle ingest <מזהה מטלה>
```
משיכה. בפעם הראשונה של מטלה חדשה מוסיפים `--course "Linear Algebra" --name "Assignment 1 - Vectors"`.

```bash
python -m moodle upload <מזהה מטלה>
```
הכנת ההחזרה לתיקייה `3 - Ready to upload to Moodle`.

```bash
python -m moodle status <מזהה מטלה>
```
מראה מה כבר נעשה במטלה.

אותן פעולות זמינות גם בכפתורים של האתר המחובר (ראו [`dashboard/`](../dashboard/)).

**מזהה המטלה** הוא המספר `id=` בכתובת של המטלה במודל. הוא גם המספר בסוף שם ה-ZIP.

ההסבר המלא נמצא ב-[`CLAUDE.md`](../CLAUDE.md): איך מורידים, איך מעלים, ובעיות שכבר נפתרו.

הבדיקות נמצאות ב-[`tests/moodle/`](../tests/moodle/).
